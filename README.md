# Time to Decimal Calculator

A premium, animated, SEO-optimized page for the keyword **"time to decimal calculator"**.

## Files

| File | Purpose |
|------|---------|
| index.html | Main page with the calculator, animated luxury design and 1000+ word article |
| robots.txt | Tells search engines which pages to crawl and where the sitemap is |
| sitemap.xml | Lists the page URL for search engine indexing |
| README.md | Project documentation |

## Features

- Time to decimal (hours, minutes, seconds) and decimal to time converters
- Live updates while typing
- Luxury gold theme with animated background, shimmer heading and fade-in effects
- Inline SVG illustrations that load instantly with no external requests
- Semantic HTML5 structure (header, main, article, figure, section, footer)
- Meta tags, Open Graph, Twitter cards and WebApplication JSON-LD schema
- Responsive layout for mobile and desktop
- Respects reduced-motion preferences for accessibility

## Setup

1. Upload `index.html`, `robots.txt` and `sitemap.xml` to the root of your domain or to the folder that matches `https://sumhours.com/time-to-decimal-calculator/`.
2. Make sure `robots.txt` uses exactly that lowercase name.
3. Submit `https://sumhours.com/sitemap.xml` in Google Search Console.
4. Open the page and test the calculator on mobile and desktop.

## Customization

- Replace the canonical and Open Graph URLs if your page path changes.
- Update the copyright text in the footer.
- Change the colors in the `:root` section of the CSS to match another theme.
